## Roxy Web
Marketing/landing site for **Roxy CosLab** built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

## Docs
- Developer documentation: `DOCUMENTATION.md`

## Getting Started
- Install: `npm install`
- Dev server: `npm run dev` (open `http://localhost:3000`)
- Lint: `npm run lint`
- Build: `npm run build`
- Start (prod): `npm run start`

## Where Things Live
- Home page composition: `src/app/page.tsx`
- Section components: `src/components/sections/`
- Shared UI wrapper: `src/components/ui/Container.tsx`
- Static assets: `public/assets/`
